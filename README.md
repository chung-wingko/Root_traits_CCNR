## This repository contains all data, statistical analyses, and visualisations for soil and root samples from Singapore across 3 forest types. There is a separate folder for the manuscript version (Plants, People, Planet, December 2026; https://doi.org/10.1002/ppp3.70310) and the thesis version (2025; https://doi.org/10.32657/10356/214410).

### The samples analysed in this study were collected with Permit Numbers NP/RP21-124 and NP/RP23-037 issued by the National Parks Board of Singapore. This research was funded by Singapore Ministry of Education Tier 1 grant 2019-T1-002-020.
